This website opened on {{< meta date >}}. It is the public source for MOVES Utilities releases.

The site has four parts:

- [Releases](../releases/index.qmd) has the current installer and the notes for each version.
- [Known issues](../known-issues.qmd) lists open problems and workarounds.
- [Compatibility](../compatibility.qmd) lists the MOVES versions each release works with.
- [News](index.qmd) lists announcements.

MOVES Utilities 0.5.9 is the first public release.

To receive notice of new versions, select **Watch**, then **Custom**, then **Releases** on the [GitHub repository](https://github.com/ttitamu/moves-utilities). You can also subscribe to the [news RSS feed](index.xml).
