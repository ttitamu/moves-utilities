## Changes

This is the first public version. It includes:

### Emission Rate workflow

- Builds county databases (CDBs) and MOVES run specifications for emission rate runs, using county input data that the application downloads.
- Loads the county databases into MariaDB and starts the MOVES runs.
- Sets the project type to Transportation Conformity. It cannot be changed.
- Selects the conformity pollutants and processes by default. You can still adjust individual pairs.
- Offers two CDB templates: Summer Only, and Summer + Winter.
- Limits the day type to Weekday.

### Emission Inventory workflow

- Adjusts the MOVES emission rates, including TxLED and refueling adjustments.
- Calculates hourly on-network travel (VMT and VHT) from your road network files.
- Calculates off-network activity: vehicle population, engine starts, idling, parking, and hotelling.
- Multiplies activity by the emission rates to calculate hourly emissions.
- Writes link-level emission files (optional).
- Imports the analysis years and day types from the MRS Values table on the Emission Rate tab.

### Post-Processing workflow

- Builds MOVES input tables, county databases, and run specifications for emission inventory runs. You run MOVES for these outside the application.
- Writes tab files with hourly activity and emissions by county and roadway type, and 24-hour county totals.

### Application and installer

- Installs per user, without administrator rights.
- Shows Present or Missing status for each input file, with a Re-import option.
